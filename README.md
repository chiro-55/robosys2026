# foodコマンド
![test](https://github.com/chiro-55/robosys2026/actions/workflows/test_food.yml/badge.svg)

標準入力から読み込んだアルファベット1文字を頭文字とする食べ物の単語を表示する。


## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.10〜3.14

## テスト環境
- Ubuntu 24.04 LTS
